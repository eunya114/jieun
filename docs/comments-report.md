# 화면 주석 요약

## 디자인 토큰 — `docs/tokens.json`
- 목적: 모든 화면이 함께 쓰는 색·글자 크기·간격·모서리 값 모음
- 관련 유저 스토리: 해당 없음 (공통 값)
- 화면 상태: 해당 없음
- 들어오는 곳 / 나가는 곳: design.md → 화면 코드
- 주석 방식: JSON은 주석을 달 수 없는 형식이라 원본은 그대로 두고, 설명을 [tokens.md](tokens.md)에 따로 썼어요.
- 단 주석: 파일 요약 1개 + 묶음 설명 5개 + 토큰 99개 전부 설명 (색·글자는 하나씩, 간격·모서리는 묶어서) + [확인 필요] 5개
