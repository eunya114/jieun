# screens.md — 화면 설계서

## 요금제 추천

### 목적
추천 요금제를 비교하고 상세 정보를 확인할 요금제를 선택한다.

### 라우트
미정 — 선택한 자료에 경로가 명시되어 있지 않음.

### 구성 요소
- Header
  - 화면 제목: 요금제 추천
  - icon/arrowLeft
- Card/Plan
  - 기본 요금제: 데이터 5GB · 통화 100분 · 월 19,000원
  - 표준 요금제: 데이터 15GB · 통화 무제한 · 월 29,000원
  - 무제한 요금제: 데이터 무제한 · 통화 무제한 · 월 49,000원
  - Tag: 추천
  - Button: 요금제 보기
    - Type=Secondary, Size=sm, State=Default

### 상태
- 기본: 추천 요금제 3개와 각 요금제의 제공량, 월 요금, 상세 진입 버튼을 표시한다.
- 로딩: 선택한 자료에 정의되어 있지 않음.
- 빈: 선택한 자료에 정의되어 있지 않음.
- 에러: 선택한 자료에 정의되어 있지 않음.

### 이동
- 들어오는 곳:
  - 서비스 시작.
  - 요금제 상세에서 다른 요금제 보기 선택.
- 나가는 곳:
  - 요금제 카드 또는 요금제 보기 선택 → 요금제 상세.

## 요금제 상세

### 목적
선택한 요금제의 가격, 혜택, 조건을 확인하고 신청 여부를 결정한다.

### 라우트
미정 — 선택한 자료에 경로가 명시되어 있지 않음.

### 구성 요소
- Header
  - 화면 제목: 요금제 상세
  - icon/arrowLeft
- Card/Plan
  - 선택한 화면의 예시: 표준 요금제
  - 데이터 15GB 제공 · 국내 음성 통화 무제한 · 문자 메시지 기본 제공
  - 월 29,000원
  - Tag: 추천
  - Button: 상세 보기
    - Type=Secondary, Size=sm, State=Default
- 신규/조건정보
  - 부가세 포함
  - 매월 등록한 카드로 요금 결제
  - 제공량 소진 시 추가 요금 발생 가능
- Button: 다른 요금제 보기
  - Type=Secondary, Size=sm, State=Default
- Button: 신청하기
  - Type=Primary, Size=xl, State=Default

### 상태
- 기본: 선택한 요금제의 정보와 신청 조건을 표시한다.
- 로딩: 선택한 자료에 정의되어 있지 않음.
- 빈: 선택한 자료에 정의되어 있지 않음.
- 에러: 선택한 자료에 정의되어 있지 않음.

### 이동
- 들어오는 곳:
  - 요금제 추천에서 요금제 선택.
  - 신청 폼의 요금제 상세로 선택.
- 나가는 곳:
  - 다른 요금제 보기 선택 → 요금제 추천.
  - 신청하기 선택 → 신청 폼.
  - 상세 보기의 별도 이동 대상은 선택한 자료에 정의되어 있지 않음.

## 신청 폼

### 목적
요금제 신청에 필요한 개인 정보와 결제 정보를 입력하고 약관에 동의한다.

### 라우트
미정 — 선택한 자료에 경로가 명시되어 있지 않음.

### 구성 요소
- Header
  - 화면 제목: 신청 폼
  - icon/arrowLeft
- 선택 요금제 표시
  - 별도 컴포넌트가 아닌 화면 내 텍스트
  - 선택한 화면의 예시: 표준 요금제 · 월 29,000원
  - 요금제 상세로
- 신규/입력항목
  - Input: 이름
  - Input: 연락처
  - Input: 이메일
  - Input: 카드번호
  - Input: 유효기간
  - 화면에 사용된 Input 변형: State=default
- 신규/약관동의
  - Checkbox: State=default
  - [필수] 서비스 이용 약관에 동의합니다.
- Button: 신청하기
  - Type=Primary, Size=xl, State=Default

### 상태
- 기본:
  - 이름, 연락처, 이메일, 카드번호, 유효기간 입력란을 표시한다.
  - 약관 동의 체크박스는 선택되지 않은 상태로 표시한다.
  - 입력 정보와 약관 동의 여부를 확인하도록 안내한다.
- 로딩: 입력 정보 검사 통과 후 신청 완료 처리 중으로 이동한다.
- 빈:
  - 입력 전 안내 문구를 표시한다.
  - 이름: 이름을 입력해 주세요
  - 연락처: 010-0000-0000
  - 이메일: example@email.com
  - 카드번호: 0000-0000-0000-0000
  - 유효기간: MM / YY
- 에러: 입력 정보 유효성 검사에서 오류가 발견되면 신청 폼 · 입력 오류로 이동한다.

### 이동
- 들어오는 곳:
  - 요금제 상세에서 신청하기 선택.
  - 신청 폼 · 입력 오류에서 입력 정보 수정.
  - 실패 안내에서 신청 폼으로 돌아가기 선택.
- 나가는 곳:
  - 요금제 상세로 선택 → 요금제 상세.
  - 신청하기 선택 후 입력 오류 발견 → 신청 폼 · 입력 오류.
  - 신청하기 선택 후 검사 통과 → 신청 완료 처리 중.

## 신청 폼 · 입력 오류

### 목적
입력 정보의 오류를 안내하고 신청자가 정보를 수정하도록 한다.

### 라우트
미정 — 선택한 자료에 경로가 명시되어 있지 않음.

### 구성 요소
- Header
  - 화면 제목: 신청 폼
  - icon/arrowLeft
- 신규/오류안내
  - 입력 정보를 확인해 주세요.
  - 이메일 주소 형식이 올바르지 않습니다.
- 신규/입력항목
  - Input: 이름
  - Input: 연락처
  - Input: 이메일
  - Input: 카드번호
  - Input: 유효기간
  - 화면에 사용된 Input 원본 변형: State=default
  - 이메일 입력란의 오류 문구: 올바른 이메일 주소를 입력해 주세요.
  - icon/infoFill
- 신규/약관동의
  - Checkbox: State=active
  - [필수] 서비스 이용 약관에 동의합니다.
- Button: 입력 정보 수정
  - Type=Primary, Size=xl, State=Default

### 상태
- 기본: 입력한 개인 정보, 결제 정보와 약관 동의 상태를 유지한 채 오류를 표시한다.
- 로딩: 선택한 자료에 정의되어 있지 않음.
- 빈: 별도의 빈 상태는 선택한 자료에 정의되어 있지 않음.
- 에러:
  - 선택한 화면은 이메일에 hong@가 입력된 형식 오류 예시이다.
  - 상단 오류 안내와 이메일 입력란의 오류 문구를 함께 표시한다.
  - 다른 입력 항목의 구체적인 오류 조건과 문구는 선택한 자료에 정의되어 있지 않음.

### 이동
- 들어오는 곳:
  - 신청 폼에서 입력 정보 유효성 검사 중 오류 발견.
- 나가는 곳:
  - 입력 정보 수정 → 신청 폼의 입력 단계로 돌아가 수정한다.
  - 수정 후 신청 폼의 유효성 검사를 다시 거친다.

## 신청 완료 처리 중

### 목적
입력 정보 검사 통과 후 신청 결과가 나올 때까지 처리 중임을 안내한다.

### 라우트
미정 — 선택한 자료에 경로가 명시되어 있지 않음.

### 구성 요소
- Header
  - 화면 제목: 신청 처리
  - icon/arrowLeft
- 신규/처리중안내
  - 신청 완료 처리 중...
  - 입력 정보 확인이 완료되었습니다.
  - 신청 결과가 나올 때까지 잠시만 기다려 주세요.
- 화면 내 안내 텍스트
  - 처리가 끝나면 신청 결과가 표시됩니다.

### 상태
- 기본: 신청 처리가 진행 중임을 안내한다.
- 로딩: 신청 결과를 기다리며 처리 중 안내를 표시한다.
- 빈: 선택한 자료에 정의되어 있지 않음.
- 에러: 신청 처리에 실패하면 실패 안내로 이동한다.

### 이동
- 들어오는 곳:
  - 신청 폼에서 입력 정보 유효성 검사 통과.
- 나가는 곳:
  - 처리 실패 → 실패 안내.
  - 처리 성공 → 신청 완료.

## 실패 안내

### 목적
신청 처리 실패를 알리고 신청 폼으로 돌아가 다시 신청하도록 안내한다.

### 라우트
미정 — 선택한 자료에 경로가 명시되어 있지 않음.

### 구성 요소
- Header
  - 화면 제목: 신청 실패
  - icon/arrowLeft
- 신규/실패안내
  - 신청을 완료하지 못했습니다.
  - 신청 처리 중 문제가 발생했습니다.
  - 신청 정보를 다시 확인해 주세요.
- 화면 내 안내 텍스트
  - 신청 폼으로 돌아가 다시 신청해 주세요.
- Button: 신청 폼으로 돌아가기
  - Type=Primary, Size=xl, State=Default

### 상태
- 기본: 신청 처리 실패 안내와 신청 폼 복귀 버튼을 표시한다.
- 로딩: 선택한 자료에 정의되어 있지 않음.
- 빈: 선택한 자료에 정의되어 있지 않음.
- 에러:
  - 신청 처리 실패 결과를 표시한다.
  - 구체적인 실패 원인별 분기나 별도 문구는 선택한 자료에 정의되어 있지 않음.

### 이동
- 들어오는 곳:
  - 신청 완료 처리 중에서 처리 실패.
- 나가는 곳:
  - 신청 폼으로 돌아가기 선택 → 신청 폼.

## 신청 완료

### 목적
신청 성공을 안내하고 발급된 확인 번호와 신청 요금제 정보를 보여준다.

### 라우트
미정 — 선택한 자료에 경로가 명시되어 있지 않음.

### 구성 요소
- Header
  - 화면 제목: 신청 완료
  - icon/arrowLeft
- 신규/완료안내
  - 신청이 완료되었습니다.
  - 요금제 신청이 정상적으로 처리되었습니다.
  - 발급된 확인 번호를 확인해 주세요.
- 신규/확인번호
  - 확인 번호
  - 선택한 화면의 예시: 20261020-001234
- 신청 요금제 표시
  - 별도 컴포넌트가 아닌 화면 내 텍스트
  - 선택한 화면의 예시: 표준 요금제 · 월 29,000원
- Button: 홈으로 이동
  - Type=Primary, Size=xl, State=Default

### 상태
- 기본: 신청 완료 안내, 발급된 확인 번호, 신청 요금제와 월 요금을 표시한다.
- 로딩: 선택한 자료에 정의되어 있지 않음.
- 빈: 선택한 자료에 정의되어 있지 않음.
- 에러: 선택한 자료에 정의되어 있지 않음.

### 이동
- 들어오는 곳:
  - 신청 완료 처리 중에서 처리 성공.
- 나가는 곳:
  - 홈으로 이동 선택 → 플로우차트의 서비스 종료 / 홈으로 이동.
  - 홈 화면의 구성과 경로는 선택한 자료에 없어 별도 화면으로 추가하지 않는다.
